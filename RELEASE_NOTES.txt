Archotech Eye - Invisibility Detection 1.1.0-beta.5
Validated against the installed RimWorld 1.7 runtime, 2026-10-20.

- Added silhouette readability controls to the ordinary mod settings:
  opacity from 15% to 80%, plus original, cyan, gold and white highlights.
- Kept the original 30% opacity and original colors as the default,
  including when loading older settings without the new fields.
- Added a one-click readability preset (60% opacity, cyan) and a separate
  appearance reset that does not change Alpha Animals compatibility.
- Changes apply on the next world draw to currently cached detections.
  Portraits, atlas/cache passes and undetected pawns remain untouched.
- Retains the native fade-capable material. The highlight blends with
  the incoming tint; final appearance still depends on original textures.
- No change to detection range, line of sight, the 60-tick cache, native
  invisibility, per-observer targeting or discovery events. No extra scans,
  draw calls, materials or line-of-sight checks were added to rendering.
- Settings persist through native Scribe. Non-finite opacity and unknown
  palette values are normalized safely. English/Korean labels included.
- Both 1.6 and 1.7 Release builds passed without warnings/errors. Each
  DLL passed 229 runtime assertions with Alpha Animals, 188 without it,
  under the installed 1.7 engine. Includes real Ratkin Anomaly classes,
  Alpha Animals versions, setting persistence and old-config migration.
- These are headless state/patch/render-parameter tests. The in-game
  settings UI and final visuals still need a visual playtest; there was
  no real 1.6 engine playtest.
- Steam uploads require an explicit request for each release. Development
  and GitHub updates never trigger automatic Steam publication.

Previous release: 1.1.0-beta.4
Validated against the installed RimWorld 1.7 runtime, 2026-10-20.

- Reproduced Alpha Animals' stalking event bypassing native invisibility
  detection, using its actual stalking hediff class and installed XML.
- Added a separate optional adapter for that state. It uses the actual
  Hediff_Stalking type, not a race check, DefName guess or texture-name scan.
- Keeps native psychological invisibility and original animal targeting
  rules unchanged. The stalking hediff is never removed to reveal a pawn.
- Uses the normal 36-tile, line-of-sight, 60-tick per-observer cache. Only
  player-controlled colonists contribute to the player's silhouette cache.
- Bypasses only Alpha Animals' hidden-graphics branch for cached detections,
  preserving its ordinary and alternate-graphics branches. Requests the
  game's fading material and alpha 0.3 without doing LoS work in rendering.
- Clears both caches on map removal and invalidates graphics when custom
  visual-state membership changes, even if native detection stays active.
- Added an Alpha Animals stalking-detection checkbox in mod settings.
  Enabled by default for the supported API; changes apply within 60 ticks.
  Native-system detection is independent of this option.
- Missing Alpha Animals registers no optional patch. An unexpected graphics
  method shape disables the adapter instead of guessing how to patch it.
- Diagnostics distinguish supported custom stalking from native invisibility
  and report when the optional setting is disabled, in English and Korean.
- Both 1.6 and 1.7 Release builds passed with no warnings/errors. Runtime
  checks passed: 160 with Alpha Animals, 120 without it. Both versions of
  Alpha Animals' DLL were checked under the installed 1.7 runtime.
- These are headless state/patch/render-parameter tests, not a visual
  playtest or a real 1.6 engine test. In-game silhouette/settings UI still
  need visual verification.
- Steam uploads require an explicit request for each release. Development
  and GitHub updates never trigger automatic Steam publication.

Previous release: 1.1.0-beta.3
Validated against RimWorld 1.7.4982 rev1280, 2026-10-19.

- Added an on-demand developer action under Archotech Eye:
  Inspect invisibility compatibility. Click a pawn's cell to inspect it,
  including invisible pawns. The report is available in English and Korean.
- Reports the game's invisibility and hidden-from-player predicates with
  only this mod's reveal override suppressed. Other mods' patches remain
  active and their Harmony owner IDs are listed.
- Includes pawn/hediff DefNames, classes, assemblies, source mods/package
  IDs, native invisibility component states, and ThingComp type metadata.
- Shows per-observer cached detection separately from current distance
  and line of sight. It never refreshes or changes the detection cache.
- Distinguishes active game invisibility, an inactive native component,
  missing native evidence, and failed/unavailable evaluation. Missing
  evidence does not prove a custom stealth system.
- Exceptions from predicate/component evaluation are shown in the report;
  custom stealth properties are not probed or executed by reflection.
- Includes a Write Report to Log button. No new letter or automatic
  notification is added. No diagnostics run during ticking or rendering.
- Kept the 36-tile radius, 60-tick refresh, silhouette alpha and Ratkin
  Anomaly discovery-event behavior unchanged.
- Both 1.6 and 1.7 Release builds passed without warnings/errors.
  116 assertions passed for each DLL under the installed 1.7 runtime.
  A real 1.6 runtime and the in-game dialog were not visually playtested.
- Steam publication is handled manually by the user. Repository updates
  do not automatically upload this mod to Steam Workshop.

Previous release: 1.1.0-beta.1
Tested against RimWorld 1.7.4977 rev1248 (unstable), 2026-10-15.

Requirements: Harmony and Anomaly.

RimWorld 1.7:
- Separate .NET 10 assembly, using the game's UnityStubs compatibility types.
- Fixed manual attack targeting without reflective ThingsUnderMouse calls.
- Preserved downed, dormant and inactive threat exclusions during detection.
- Covered both ordinary and interval pawn ticks and both cast overloads.
- Restored observer context even when combat or target enumeration throws.
- Read the game's full invisibility predicate, including multiple hediffs.
- Published read-only detection snapshots for parallel render readers.
- Rebuilt graphics only when player-visible detection changes.
- Corrected the detection message to identify Revenant (Korean: mangryeong).

Compatibility:
- 18 tiles, line of sight, alpha 0.3, refresh every 60 game ticks.
- Detection changes can take up to 60 ticks to appear/disappear.
- No pop-up letters. A short detection message is retained.
- No metalhorror implant detection.
- RimWorld 1.6 loads the previously released, unchanged .NET Framework DLL.
- Languages are shared through Common/. LoadFolders.xml selects one DLL.

Validation:
- Release build: no warnings or errors.
- 51 assertions using the installed 1.7 game assemblies and Waylith CLR.
- Includes Harmony registration, observer isolation, lazy targeting,
  exceptions, multiple invisibility comps, radius boundary, wall blocking,
  inactive target exclusions, silhouette alpha, portraits and despawning.
- Automated checks do not replace visual playtesting of this beta build.
